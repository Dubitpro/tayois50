# Music Management Guide

This document explains how to add new music to the website's dynamic music player using Firebase Firestore and Cloudinary.

## Prerequisites
1. Access to the [Firebase Console](https://console.firebase.google.com/) for your project.
2. Access to your [Cloudinary](https://cloudinary.com/) dashboard to host audio and cover image files.

## Adding a New Song

To add a new song to the music player, follow these exact steps:

### 1. Upload Audio and Cover to Cloudinary
1. Open your Cloudinary Media Library.
2. Upload the MP3 or audio file you have legal rights to stream.
3. Upload the square cover artwork for the song.
4. Copy the **secure URL (HTTPS)** for the uploaded **audio file**. It should look like: `https://res.cloudinary.com/.../video/upload/.../song.mp3`.
5. Copy the **secure URL (HTTPS)** for the uploaded **cover artwork image**. It should look like: `https://res.cloudinary.com/.../image/upload/.../cover.jpg`.

*Important: Do not use YouTube, Spotify, or Apple Music URLs. The player requires a direct, browser-playable audio URL like the ones generated by Cloudinary.*

### 2. Add the Song to Firestore
1. Go to your Firebase Console.
2. Navigate to **Firestore Database**.
3. Locate the `music` collection (if it does not exist, click "Start collection" and name it `music`).
4. Click **Add document** to create a new song entry. (Leave Document ID as Auto-ID).
5. Add the following fields to the document exactly as shown:

| Field Name | Type | Value | Description |
| :--- | :--- | :--- | :--- |
| `title` | string | "Your Song Title" | The name of the song. |
| `artist` | string | "Artist Name" | The name of the artist. |
| `audioUrl` | string | "https://res..." | The Cloudinary secure URL for the audio file. |
| `coverUrl` | string | "https://res..." | The Cloudinary secure URL for the cover artwork. |
| `category` | string | "Worship" | (Optional) The category or genre. |
| `duration` | number | 0 | (Optional) The duration in seconds (0 is fine, it will auto-detect). |
| `published` | boolean | true | Set to `true` to make it visible on the website. |
| `createdAt` | timestamp | (Select current date/time) | The upload date, used for sorting. |

6. Click **Save**.

### 3. Verification
The music player uses real-time Firestore listeners. The moment you click Save in Firebase, the song will automatically appear on the live website and be available for playback. No redeployment or coding is required.

## Updating or Hiding a Song
- To **hide** a song without deleting it, edit the document in Firestore and change the `published` field to `false`.
- To **update** a song (e.g., change the title or artwork), simply edit the corresponding fields in Firestore.
- To **delete** a song permanently, delete the document from Firestore.

## Future Architecture Note
The architecture of this system has been designed cleanly so that in the future, a dedicated Admin Dashboard can be built to handle these uploads and data entries automatically from within the app itself, without needing to visit Firebase or Cloudinary directly.
